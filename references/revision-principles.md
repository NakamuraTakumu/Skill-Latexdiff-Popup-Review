# Revision principles

これは論文全体の査読基準でも原稿を編集する指示でもない。
popup comment で原稿差分を評価するための安全制約である。

## 適用範囲

**意味単位**：差分が一つの意味を担う最小のまとまりである。
文、式、図、引用、参照、構造的な LaTeX command を含む。

**構造的差分**：`\\item`、環境の開始と終了、`\\bibitem`、参照 command などの差分である。
本文と同じ基準で意味単位として評価する。

Main は原稿を修正せず、各意味単位の所見を manifest の popup ID へ対応付ける。
修正が必要な場合も、comments で対象位置と最小の具体的な変更を示す。

## 評価制約

- **意味保持**：主張、含意、論理関係、帰属、確実性、限定条件を暗黙に変えていないか確認する。
- **最小修正**：依頼された修正を満たす局所的な変更を優先する。
  広い書き換えまたは不要な周辺への波及は問題として扱う。
- **未依頼内容の追加禁止**：求められていない主張、根拠、比較、例、留保、解釈、引用、仕様、結論を差分へ追加していないか確認する。
- **範囲保持**：安全な局所修正に必要でない限り、指定範囲、環境種別、節構成、段落構成を変えていないか確認する。
- **一貫性保持**：既存の文体、用語、記法、著者の声、近傍の反復 pattern、および文書内の参照と矛盾しないか確認する。
- **文字数制限**：文字数、語数、ページ数などの制限があるとき、実測値が制限内である文章を余白確保だけのために削っていないか確認する。
  削減は、実測超過の解消、明示された目標値への調整、または具体的な追加予定に必要な最小範囲に限る。
- **既存 TODO 保持**：明示的に依頼されていない TODO marker を、埋める、削除する、解決済みとして扱う変更は問題として扱う。
- **引用文と macro**：command の差し替えだけで済ませず、文全体と修辞上の接続を確認する。

## 判断と表示確認

入力 artifact から判断できない場合は `[意味変化要確認]` または `[要確認]` とし、根拠のない `[OK]` を付けない。

位置、改行、数式、図、参照、caption、front matter、page break、visual annotation など、表示結果が評価対象またはリスク対象である場合は、source だけで判断しない。
注釈前の差分 PDF を確認する。

所見は、該当する popup ID、変更された意味単位、判断理由、必要な最小修正を具体的に結び付ける。
manifest の全 ID を対象にし、delete と add を別々に評価する。
