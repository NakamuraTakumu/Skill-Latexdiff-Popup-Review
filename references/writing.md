# Popup comment writing

- Write concise, specific comments in the requested language (Japanese by default).
- Start with the required meaning and evaluation labels, then explain the reason.
- Distinguish observed changes from uncertainty and proposed corrections.
- Identify the changed wording, equation, reference, or structure; avoid generic praise.
- Do not invent evidence, citations, author intentions, or manuscript content.
- These rules govern comment wording only; the fixed workflow and permissions take precedence.
